  Key Capabilities

  Context Window Manager (AgentX.Core.AI)
  - Conservative token estimation (~4 chars/token + per-message overhead)
  - Two-phase trimming: FIFO removal of oldest messages, then content truncation
  - Always preserves system prompt + last 4 conversation messages
  - Logs warnings when trimming occurs
  - Effective context window clamping (default 4096, cap 128K)

  Exponential Backoff Retry Policy (AgentX.Core.AI)
  - Base 500ms delay, doubling each retry (500ms → 1s → 2s)
  - Random jitter of ±25% to prevent thundering herd
  - Smart transient detection: retries HTTP errors, timeouts, connection failures
  - Does NOT retry permanent errors (bad arguments, unsupported operations)
  - Respects user cancellation tokens

  RAG Reranker (AgentX.Core.Search)
  - Near-duplicate detection via Jaccard similarity (>85% threshold)
  - Query relevance boosting (up to 1.5x for chunks with query term hits)
  - Document diversity enforcement (caps any single document at 60% of context)
  - Pipeline: Deduplicate → Boost → Diversify → Sort → Take top-K
