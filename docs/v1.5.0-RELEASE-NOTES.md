# Agent-X v1.5.0 Release Notes

**Release Date:** April 2026

---

## Overview

Agent-X v1.5.0 delivers four major features from the Expansion tier of the Value Ladder roadmap: Web Content Ingestion Depth, Conversation Branching, Export Format Expansion, and Deep Research Mode. This release deepens the knowledge vault experience — richer ingestion, richer exploration, richer output.

---

## New Features

### Web Content Ingestion Depth

Overhaul web content ingestion with JavaScript rendering, RSS/Atom feed subscription, sitemap bulk import, and deeper structured extraction.

- **JavaScript rendering** via Playwright headless Chromium — JS-heavy pages now render fully before extraction
- **RSS/Atom feed subscription** — subscribe to any RSS 2.0, RSS 1.0 (RDF), or Atom 1.0 feed; auto-import new items to Smart Inbox
- **Sitemap bulk import** — parse sitemap.xml files (including nested sitemap indexes); import up to 100 pages at once
- **Enhanced metadata extraction** — JSON-LD structured data (Schema.org Article, author extraction), HTML table to markdown conversion, canonical URL resolution, article:author meta tags
- **Automatic JS fallback** — when readability extraction returns <100 chars, WebScraperService automatically re-renders with Playwright

### Conversation Branching

Fork any conversation at any point, explore alternate paths, and merge insights back.

- **Branch from Here** action on any user message — creates a new conversation that shares the common prefix
- **Branch tree sidebar** — collapsible panel in chat sidebar showing all branches with labels and navigation
- **Side-by-side branch comparison** — dedicated comparison window showing two branches next to each other
- **Merge to Main** — merge selected messages from a branch back into the main thread
- **Branch indicators** — visual badges on messages that are branch points, showing fork count
- **Full backend** — `ConversationBranchService` with 8 methods (branch, merge, delete, get tree, get count, etc.) was already complete; this release adds the full UI

### Export Format Expansion

Export conversations in more formats with pre-built templates for professional output.

- **DOCX export** — formatted Word documents with headings, bold user messages, timestamps, citations, and metadata sections
- **PPTX export** — PowerPoint slide decks with title slide, user questions as headings, and assistant responses as content slides
- **Export templates** — three built-in templates: Research Report (Introduction → Findings → Conclusion → References), Executive Summary (Key Findings → Recommendations), Annotated Bibliography (grouped sources with summaries)
- **ExportDialog** — dedicated ContentDialog for format selection, template selection, and export options (citations, metadata, timestamps, branches)
- **Batch DOCX** — export multiple conversations into a single Word document with page breaks

### Deep Research Mode

Supplement local vault knowledge with web search results, clearly tagged as [Vault] vs [Web].

- **Research Mode toggle** — per-query toggle in chat input bar (globe icon)
- **Configurable search providers** — Brave Search API, Serper (Google), or self-hosted SearXNG
- **Web citations** — search results tagged as [Vault] (local knowledge) or [Web] (external source) with distinct colors
- **Save to Vault** — one-click action to save web results to Smart Inbox for permanent indexing
- **Result caching** — configurable TTL cache (default 60 min) reduces API calls
- **Cost tracking** — web search API calls tracked in the existing CostTracker
- **Graceful degradation** — Research Mode degrades gracefully to local-only if search API is unavailable
- **Settings UI** — full configuration panel for provider, API key, max results, and cache duration

## Bug Fixes & Improvements

- WebScraperService now falls back to JS rendering when readability extraction returns minimal content
- ExportService now supports 8 formats (up from 6): Markdown, HTML, PDF, JSON, PlainText, CSV, DOCX, PPTX
- ConversationDto now includes branching fields (ParentConversationId, BranchPointMessageId, BranchLabel, BranchCount)
- ChatViewModel now injects IConversationBranchService for branch operations
- AppSettings now includes Research Mode fields (EnableResearchMode, WebSearchProvider, WebSearchApiKey, MaxSearchResults, SearchCacheTtlMinutes)
- RagPipeline now supports `enableResearchMode` parameter for web search enrichment
- 490 unit tests passing (up from 376 in v1.4.0)

---

## Breaking Changes

- `IRagPipeline.AskAsync` now accepts `bool enableResearchMode = false` (default preserves existing behavior)
- `ExportFormat` enum expanded with `Docx` and `Pptx` members
- `ConversationDto` now has `ParentConversationId`, `BranchPointMessageId`, `BranchLabel`, and `BranchCount` properties
- `ExportOptions` now has `TemplateId` and `IncludeBranches` properties

---

## Upgrade Notes

- Playwright browsers must be installed for JS rendering: run `npx playwright install chromium` after upgrading
- Research Mode is disabled by default — enable it in Settings → Research Mode
- Browser extension users should update to the latest version for Smart Inbox source type badges
- The Export button in ChatPage now opens a full ExportDialog instead of a simple menu
