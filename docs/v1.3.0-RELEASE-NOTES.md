# Agent-X v1.3.0 Release Notes

**Release Date:** April 2026

---

## Overview

Agent-X v1.3.0 introduces six major features: Workspace Profiles, Smart Inbox, Comparative Analysis, Voice Input, Plugin API, and Collaborative Sync foundation. This release also includes the Whisper.net local transcription engine and a complete plugin development system.

---

## New Features

### Workspace Profiles (#9)

Create isolated environments for different projects or contexts. Each workspace has its own conversations, knowledge base, and AI settings.

- Create, rename, and delete custom workspaces
- Assign icons and colors for visual identification
- Switch between workspaces from the sidebar
- Data isolation per workspace directory
- Built-in Default workspace that cannot be removed

### Smart Inbox (#10)

Automated file detection and triage for your knowledge base.

- Watch folder detection for new files
- AI-powered preview generation
- Accept, Reject, or Defer individual items
- Batch operations for Accept All / Reject All
- Assign items to specific collections on accept

### Comparative Analysis (#11)

AI-powered document comparison across your knowledge base.

- Select 2+ documents for side-by-side analysis
- Choose analysis dimensions: Themes, Arguments, Methodology, Sentiment
- Structured reports with citations
- Export comparison results as Markdown
- Graceful fallback when AI response is malformed

### Voice Input & Audio Transcription (#14)

Local speech-to-text powered by Whisper models running entirely on your device.

- Click microphone button to record, click again to transcribe
- Right-click to select an existing audio file for transcription
- Supports MP3, WAV, M4A, FLAC, OGG, WebM
- Whisper model downloads (tiny through large)
- 16kHz mono recording via NAudio for optimal Whisper input
- Transcribed text inserted into chat input for review before sending

### Plugin API (#13)

Complete plugin system for extending Agent-X with third-party functionality.

- `.agentx-plugin` package format (ZIP-based)
- Plugin types: Document Processor, AI Provider, Quick Action, Workflow Step, Theme, Custom
- Isolated `AssemblyLoadContext` per plugin
- Sandboxed plugin data directory
- Permission declaration in manifest
- Install, enable, disable, uninstall lifecycle
- Sample plugin included in `plugins/sample-plugin/`

### Collaborative Sync Foundation (#15)

Data synchronization framework for multi-device and backup scenarios.

- AES-256-GCM encrypted sync packages
- Conflict detection and resolution (Keep Local, Keep Remote, Merge)
- Auto-sync with configurable intervals
- Change set export/import
- Sync history logging

## Improvements

### Chat

- Message editing (#18): Click edit on any user message to modify and resend
- Per-message actions (#18): Copy, delete, regenerate, thumbs up/down
- Conversation folders/tags (#22): Organize conversations with custom folders
- Syntax highlighting (#19): Code blocks rendered with proper formatting
- Notification toasts (#20): Non-intrusive status notifications

### AI Chat

- System prompt selection from flyout menu
- Token count and generation speed display
- Export conversations to clipboard or file
- Suggested follow-up questions

### Whisper.net Integration

- Full Whisper.net v1.5.0 integration for local speech-to-text
- Async file stream processing for efficient memory usage
- Progress reporting during transcription
- Model management (download, check availability)
- Support for all Whisper model sizes (tiny, base, small, medium, large)

## Bug Fixes

- Fixed Whisper.Net namespace resolution (`Whisper.net` not `Whisper.Net`)
- Fixed `RunWhisperAsync` static method accessing instance `_log` field
- Fixed `WhisperFactory` not implementing `IAsyncDisposable` — changed to `using` from `await using`
- Fixed `ProcessAsync` to accept `FileStream` instead of file path string

---

## Breaking Changes

- `ChatViewModel` constructor now requires `ITranscriptionService` parameter
- `TranscriptionService.RunWhisperAsync` is now an instance method (was static)
- `Whisper.net` namespace must be used instead of `Whisper.Net`

## System Requirements

| Component | Requirement |
|-----------|-------------|
| Operating System | Windows 10 v1809+ / Windows 11 |
| Runtime | .NET 8.0 Desktop Runtime |
| RAM | 8 GB minimum (16 GB recommended) |
| GPU | Optional — for Whisper model acceleration |
| AI Backend | Ollama installed and running |

---

## Known Issues

- 80 PRI resource warnings for missing default string resources (non-blocking)
- Whisper large model download may timeout on slow connections — use the `base` model for best balance of speed and accuracy
- Voice input requires microphone permissions in Windows Settings
