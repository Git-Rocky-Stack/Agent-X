# Agent-X v1.4.0 Release Notes

**Release Date:** April 2026

---

## Overview

Agent-X v1.4.0 delivers four major features from the Foundation + First Expansion tier of the Value Ladder roadmap: DPAPI API Key Encryption for trust, System Tray + Global Hotkey for accessibility, a Chrome/Edge Browser Extension for web content capture, and Multi-Model Routing for seamless AI provider switching. This release addresses the top competitive gaps and user workflow issues identified in the strategic gap analysis.

---

## New Features

### DPAPI API Key Encryption

API keys are now encrypted at rest using Windows DPAPI (Data Protection API). Keys are encrypted per-user, per-machine — only Agent-X running as the current Windows user can decrypt them.

- Automatic migration of plaintext keys on first launch
- `DpapiEncryptionService` encrypts with `ProtectedData.Protect()` using `CurrentUser` scope
- Encrypted values prefixed with `DPAPI:` for identification
- Settings UI shows green "API Keys Secured" status indicator
- Zero-configuration — encryption happens transparently on save

### System Tray + Global Hotkey

Agent-X now runs as a native system utility with always-available access.

- System tray icon with AI connection status, model name, and document count
- Minimize-to-tray on window close (configurable)
- Right-click context menu: Open Agent-X, Quick Chat, Settings, Exit
- **Win+Shift+A** global hotkey opens Quick Chat overlay from any application
- Quick Chat overlay: always-on-top, semi-transparent, streams AI responses against your knowledge vault
- Dynamic tooltip updates in real-time as AI status changes

### Browser Extension (Chrome/Edge)

Clip web content directly into your Agent-X knowledge vault from any browser.

- **Three clip modes:** Full Page, Selection, Reader Mode
- **Batch clip:** Clip all open tabs at once
- **Smart Inbox integration:** Clipped pages appear in Smart Inbox for triage
- **Metadata preservation:** Title, author, published date, source URL, word count
- **Connection status:** Extension shows whether Agent-X is running
- **Recent clips history:** Last 10 clips stored locally
- Manifest V3, works with Chrome and Edge
- All communication via localhost — no cloud intermediary

### Multi-Model Routing

Intelligently route queries to the best available AI model based on task type.

- **Task type detection:** Automatically classifies prompts as extraction, summarization, analysis, generation, code, creative, or chat
- **Explicit tags:** Use `[analysis]`, `[code]`, etc. in your prompt to override detection
- **Three routing profiles:**
  - *Cost Optimized* — Local models first, cloud only when necessary
  - *Quality Optimized* — Best model for each task, regardless of cost
  - *Balanced* — Local for routine tasks, cloud for complex ones
- **Per-response indicator:** See which model was selected and why
- **Fallback chains:** If preferred model is unavailable, automatically switches to next best
- Opt-in via Settings toggle — existing manual switching still works

## Bug Fixes & Improvements

- Settings now properly encrypt API keys at rest (previously stored in plaintext)
- System tray icon correctly reflects AI connection status in real-time
- API host now supports CORS for browser extension origins
- New `/api/inbox/clip` endpoint for programmatic document ingestion
- New `/api/extension/health` endpoint for extension connectivity check
- Smart Inbox items now show source type (Web Clip badge for browser-sourced content)
- 105 new unit tests (376 total, up from 271)

---

## Security

- **DPAPI encryption:** All API keys (OpenAI, Anthropic) are now encrypted using Windows DPAPI with `DataProtectionScope.CurrentUser`. No plaintext keys are written to disk after first launch.

---

## Breaking Changes

- `InboxService.AddToInboxAsync` now accepts optional `sourceType` and `sourceUrl` parameters
- `SettingsService` constructor now requires `IDpapiEncryptionService` dependency
- `ApiHostService` constructor now requires `IInboxService` dependency

---

## Upgrade Notes

- On first launch after upgrading, Agent-X automatically migrates any plaintext API keys in `settings.json` to DPAPI-encrypted format
- The browser extension must be installed separately — it is not bundled with the desktop app
- Multi-model routing is disabled by default — enable it in Settings → Model Routing
