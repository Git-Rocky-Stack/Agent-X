## 1. Data layer

**#7 — `created=false` on fresh install.** `MigrationRunner.RunCoreAsync` previously read
`CanConnectAsync()`, which is `true` even on a fresh install because `EnsureKeyApplied()`
pre-creates the empty `.db`. It now computes `databaseExistedBefore = hadHistoryTable ||
hadApplicationTables` from `sqlite_master`. Baseline-adoption gating is unchanged in behaviour.
New test: `RunAsync_reports_DatabaseCreated_true_when_schema_absent_despite_preopened_file`.

**#6 — `licenses` table.** Empirically disproved at runtime. New test
`RunAsync_on_fresh_database_does_not_leave_the_licenses_table` asserts zero `licenses` tables
after `MigrationRunner.RunAsync()` — passes. `DropLicensesTable` works; the snapshot is clean.

## 2. App — belief-conflict persistence (#8)

`ITemporalIdentityService.AcknowledgeConflictAsync(conflictId)` persists `HasBeenAcknowledged` +
`AcknowledgedAt` and saves. `DashboardViewModel.AcknowledgeConflictAsync` is `async` again and
awaits it. Tests:
`AcknowledgeConflictAsync_persists_so_conflict_does_not_resurface_after_restart`,
`AcknowledgeConflictAsync_returns_false_for_unknown_conflict`.

## 3. Installer — dual profiles + hygiene (#2, #3, #4, #5)

`installer/AgentX-Setup.iss` is now a two-profile script (Inno `AgentXOffline` flag):

| Profile | Command | Output | Model | Hosting |
|---|---|---|---|---|
| SLIM | `ISCC AgentX-Setup.iss` | `AgentX-Setup-2.1.1-x64.exe` (~180 MB) | downloaded on first run | GitHub Release |
| OFFLINE | `ISCC /DAgentXOffline=1 AgentX-Setup.iss` | `…-x64-offline.exe` (~2 GB) | bundled, `uninsneveruninstall` | Cloudflare R2 |

Also: `VersionInfoVersion=2.1.1` (#4), removed unused `Data\` dir (#5).

New tooling:
- `scripts/build-installers.ps1 [-Profiles slim|offline|both] [-SkipPublish]` — publish + ISCC both.
- `scripts/publish-offline-installer.ps1` — upload OFFLINE installer to R2 via **rclone** (multipart;
  wrangler's `r2 object put` caps at 315 MB). Reads R2 **S3** creds from env: `R2_ACCESS_KEY_ID`,
  `R2_SECRET_ACCESS_KEY`, `CLOUDFLARE_ACCOUNT_ID`. Public link defaults to `https://downloads.strategia-x.com`.

## 4. First-run model bootstrap (#2)

`AgentX.Core/AI/BuiltInModelBootstrap.cs` (+ interface): downloads the Llama 3.2 3B GGUF from the
public HuggingFace URL to a temp `.part` file, verifies the transfer (advertised length + size
floor, optional SHA-256), then **atomically** publishes it — a cancelled/failed download never
leaves a corrupt model. `IsInstalled()` treats a truncated leftover as not installed.
DI-registered in `App.xaml.cs`; surfaced in **Onboarding Step 3** (`OnboardingViewModel` +
`OnboardingPage.xaml`) with a Download button, progress bar, and provider activation on success.
`LocalLlmProvider.PullModelAsync` was hardened with the same atomic pattern. 6 unit tests.

## 6. How to build & ship

```powershell
$dotnet = "dotnet"  # global.json pins SDK 8.0.4xx; or use $env:USERPROFILE\.dotnet\dotnet.exe

# Build + full test suite (Release|x64)
& $dotnet build src\AgentX.App\AgentX.App.csproj -c Release -p:Platform=x64
& $dotnet test  tests\AgentX.Tests\AgentX.Tests.csproj -c Release -p:Platform=x64 --blame-hang-timeout 5m

# Both installers (SLIM needs no model; OFFLINE needs scripts\download-model.ps1 first)
scripts\build-installers.ps1 -Profiles both

# Publish OFFLINE installer to R2 and print the public link
scripts\publish-offline-installer.ps1 -Version 2.1.1 -PublicBaseUrl 'https://<your-r2-domain>'
```
