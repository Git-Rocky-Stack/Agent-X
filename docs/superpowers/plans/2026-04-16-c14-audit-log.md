# C14 — Audit Log Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Append-only, tamper-evident audit log of every data-modifying action in Agent-X. Each row carries an HMAC-SHA256 chain hash computed from the previous row's HMAC + the current payload; verification walks the chain to detect any tampering, insertion, deletion, or reordering.

**Architecture:** A new `audit_log` table with a monotonically increasing sequence number and HMAC chain. `IAuditLogService.AppendAsync(...)` is the single write path, taking an `AuditEvent` value-object (actor, action, entity-type, entity-id, metadata-JSON). `IAuditLogVerifier.VerifyAsync()` recomputes the chain and reports first-tamper index. HMAC key is generated once at encryption-provisioning time (C13 dependency), stored DPAPI-wrapped in `UserSettings` so even a DB-compromise attacker cannot forge entries without the user's Windows profile. New `AuditLogPage` UI exposes timeline + filters + CSV/JSON export. All existing data-mutating services receive audit-write calls (non-blocking, in-transaction).

**Tech Stack:** .NET 8, EF Core migrations (B9 dependency), System.Security.Cryptography HMACSHA256, System.Text.Json, CommunityToolkit.Mvvm, WinUI 3 DataGrid.

**Prerequisites:** Plans B9 (migration runner) and C13 (encryption provisioning, key-service plumbing) landed.

### Correction #1 — `UserSettings` is key-value, NOT singleton (from Spike 2 + C13 hotfix)

**This is the most important correction.** `UserSettingsEntity` is used as a **key-value store** by `FeatureFlagService` (accessed via `.FirstOrDefaultAsync(s => s.Key == key)`) and `SyncService`. It is NOT a singleton row.

Consequence for C14's `IAuditKeyService` (Task 3): the plan proposed storing `DpapiWrappedAuditKey` as a column on `UserSettingsEntity`. **This is wrong for the same reason C13's `DpapiWrappedKey` was wrong** — a predicate-less `FirstOrDefaultAsync()` would collide with feature-flag rows.

**Correct approach (mirrors C13 hotfix):** move the audit HMAC key to an out-of-DB sibling file.

- Create a new `IAuditKeyFile` service with a single responsibility: read/write the DPAPI-wrapped HMAC key at `%LocalAppData%\AgentX\audit.key.dpapi`.
- `AuditKeyService` depends on `IAuditKeyFile` + `IDpapiEncryptionService` only — NO `AgentXDbContext` dependency.
- Do NOT add a `DpapiWrappedAuditKey` column to `UserSettingsEntity` in Task 3 Step 1. The column is not needed.
- File format: the same JSON shape as `encryption.info.json` (small JSON with `{ version, dpapiWrappedKey, createdAt }`).

**Implementation shape for Task 3:**
```csharp
public interface IAuditKeyFile
{
    bool Exists();
    string? ReadWrappedKey();       // returns DPAPI ciphertext as produced by IDpapiEncryptionService.Encrypt
    Task WriteAsync(string wrappedKey);
    void Delete();
}

public sealed class AuditKeyService : IAuditKeyService
{
    private const int KeyLengthBytes = 32;
    private readonly IAuditKeyFile _file;
    private readonly IDpapiEncryptionService _dpapi;

    public AuditKeyService(IAuditKeyFile file, IDpapiEncryptionService dpapi) { ... }

    public async Task<byte[]> GetOrCreateKeyAsync()
    {
        var wrapped = _file.ReadWrappedKey();
        if (wrapped is not null)
            return Convert.FromHexString(_dpapi.Decrypt(wrapped));

        var keyBytes = RandomNumberGenerator.GetBytes(KeyLengthBytes);
        var hexKey = Convert.ToHexString(keyBytes);
        await _file.WriteAsync(_dpapi.Encrypt(hexKey));
        return keyBytes;
    }
}
```

Task 3's `AuditKeyServiceTests` must not use a DbContext fixture. Each test instantiates `IAuditKeyFile` pointing at a temp path and a real `DpapiEncryptionService`.

```csharp
using System;
using System.Security.Cryptography;
using System.Threading.Tasks;
using AgentX.Core.Data;
using Microsoft.EntityFrameworkCore;

namespace AgentX.Core.Services.Security;

public sealed class AuditKeyService : IAuditKeyService
{
    private const int KeyLengthBytes = 32;

    private readonly AgentXDbContext _db;
    private readonly IDpapiEncryptionService _dpapi;

    public AuditKeyService(AgentXDbContext db, IDpapiEncryptionService dpapi)
    {
        _db = db;
        _dpapi = dpapi;
    }

    public async Task<byte[]> GetOrCreateKeyAsync()
    {
        var settings = await _db.UserSettings.FirstOrDefaultAsync();
        if (settings is null)
        {
            settings = new Data.Entities.UserSettingsEntity();
            _db.UserSettings.Add(settings);
        }

        if (!string.IsNullOrEmpty(settings.DpapiWrappedAuditKey))
        {
            var hex = _dpapi.Decrypt(settings.DpapiWrappedAuditKey);
            return Convert.FromHexString(hex);
        }

        var keyBytes = RandomNumberGenerator.GetBytes(KeyLengthBytes);
        var hexKey = Convert.ToHexString(keyBytes);
        settings.DpapiWrappedAuditKey = _dpapi.Encrypt(hexKey);
        await _db.SaveChangesAsync();
        return keyBytes;
    }
}
```

```csharp
using System;
using System.Collections.Generic;
using System.Linq;
using System.Security.Cryptography;
using System.Text;
using System.Text.Json;
using System.Threading.Tasks;
using AgentX.Core.Data;
using AgentX.Core.Data.Entities;
using Microsoft.EntityFrameworkCore;

namespace AgentX.Core.Services.Security;

public sealed class AuditLogService : IAuditLogService
{
    private static readonly string AllZeroHmac = new string('0', 64);
    private static readonly JsonSerializerOptions JsonOpts = new()
    {
        WriteIndented = false,
        // Stable key ordering for deterministic HMAC over metadata.
        PropertyNamingPolicy = null,
    };

    private readonly AgentXDbContext _db;
    private readonly IAuditKeyService _keySvc;
    private readonly IActorContext _actor;

    public AuditLogService(AgentXDbContext db, IAuditKeyService keySvc, IActorContext actor)
    {
        _db = db;
        _keySvc = keySvc;
        _actor = actor;
    }

    public async Task<long> AppendAsync(AuditEvent evt)
    {
        var key = await _keySvc.GetOrCreateKeyAsync();
        var prev = await _db.AuditLog
            .OrderByDescending(e => e.Sequence)
            .Select(e => e.Hmac)
            .FirstOrDefaultAsync() ?? AllZeroHmac;

        var entity = new AuditLogEntity
        {
            UtcTimestamp = DateTime.UtcNow,
            Actor = _actor.GetCurrentActor(),
            Action = evt.Action.ToString(),
            EntityType = evt.EntityType,
            EntityId = evt.EntityId,
            MetadataJson = SerializeMetadata(evt.Metadata),
            PrevHmac = prev,
        };

        entity.Hmac = ComputeHmac(key, prev, entity);

        _db.AuditLog.Add(entity);
        await _db.SaveChangesAsync();
        return entity.Sequence;
    }

    public async Task<IReadOnlyList<AuditLogEntity>> QueryAsync(int skip = 0, int take = 100, AuditAction? action = null)
    {
        var q = _db.AuditLog.AsQueryable();
        if (action.HasValue)
        {
            var name = action.Value.ToString();
            q = q.Where(e => e.Action == name);
        }
        return await q.OrderByDescending(e => e.Sequence).Skip(skip).Take(take).ToListAsync();
    }

    public async Task<long> CountAsync(AuditAction? action = null)
    {
        var q = _db.AuditLog.AsQueryable();
        if (action.HasValue)
        {
            var name = action.Value.ToString();
            q = q.Where(e => e.Action == name);
        }
        return await q.LongCountAsync();
    }

    private static string SerializeMetadata(IReadOnlyDictionary<string, object>? metadata)
    {
        if (metadata is null || metadata.Count == 0) return "{}";
        var sorted = metadata.OrderBy(kv => kv.Key, StringComparer.Ordinal)
                             .ToDictionary(kv => kv.Key, kv => kv.Value);
        return JsonSerializer.Serialize(sorted, JsonOpts);
    }

    /// <summary>
    /// HMAC-SHA256 over the canonical payload:
    /// prevHex || "|" || UtcTimestamp (ISO-8601 round-trip) || "|" || Actor || "|" || Action ||
    /// "|" || (EntityType ?? "") || "|" || (EntityId ?? "") || "|" || MetadataJson
    /// </summary>
    internal static string ComputeHmac(byte[] key, string prevHmac, AuditLogEntity entity)
    {
        var payload = string.Join('|',
            prevHmac,
            entity.UtcTimestamp.ToString("O"),
            entity.Actor,
            entity.Action,
            entity.EntityType ?? string.Empty,
            entity.EntityId ?? string.Empty,
            entity.MetadataJson);
        using var hmac = new HMACSHA256(key);
        var mac = hmac.ComputeHash(Encoding.UTF8.GetBytes(payload));
        return Convert.ToHexString(mac);
    }
}
```

```csharp
using System.Linq;
using System.Threading.Tasks;
using AgentX.Core.Data;
using Microsoft.EntityFrameworkCore;

namespace AgentX.Core.Services.Security;

public sealed class AuditLogVerifier : IAuditLogVerifier
{
    private static readonly string AllZeroHmac = new string('0', 64);

    private readonly AgentXDbContext _db;
    private readonly IAuditKeyService _keySvc;

    public AuditLogVerifier(AgentXDbContext db, IAuditKeyService keySvc)
    {
        _db = db;
        _keySvc = keySvc;
    }

    public async Task<AuditLogVerificationResult> VerifyAsync()
    {
        var key = await _keySvc.GetOrCreateKeyAsync();
        var rows = await _db.AuditLog.OrderBy(e => e.Sequence).ToListAsync();
        if (rows.Count == 0)
            return new AuditLogVerificationResult(true, null, null, 0);

        var expectedPrev = AllZeroHmac;
        long checkedCount = 0;

        foreach (var row in rows)
        {
            checkedCount++;
            if (row.PrevHmac != expectedPrev)
                return new AuditLogVerificationResult(false, row.Sequence, "PrevHmac does not match preceding row's Hmac (possible deletion or reorder).", checkedCount);

            var recomputed = AuditLogService.ComputeHmac(key, expectedPrev, row);
            if (recomputed != row.Hmac)
                return new AuditLogVerificationResult(false, row.Sequence, "Row HMAC does not match recomputation (row fields tampered).", checkedCount);

            expectedPrev = row.Hmac;
        }

        return new AuditLogVerificationResult(true, null, null, checkedCount);
    }
}
```

```csharp
        var rows = await _db.AuditLog.OrderBy(e => e.Sequence).ToListAsync();
        foreach (var r in rows)
        {
            await writer.WriteLineAsync(string.Join(',',
                r.Sequence,
                r.UtcTimestamp.ToString("O"),
                CsvEscape(r.Actor),
                r.Action,
                CsvEscape(r.EntityType ?? string.Empty),
                CsvEscape(r.EntityId ?? string.Empty),
                r.Hmac,
                r.PrevHmac,
                CsvEscape(r.MetadataJson)));
        }
        await writer.FlushAsync();
    }

    public async Task ExportJsonAsync(Stream outputStream)
    {
        var rows = await _db.AuditLog.OrderBy(e => e.Sequence).ToListAsync();
        await JsonSerializer.SerializeAsync(outputStream, rows, new JsonSerializerOptions { WriteIndented = true });
    }

    private static string CsvEscape(string value)
    {
        if (value.Contains(',') || value.Contains('"') || value.Contains('\n'))
            return "\"" + value.Replace("\"", "\"\"") + "\"";
        return value;
    }
}
```

```csharp
using System;

using CommunityToolkit.Mvvm.ComponentModel;

using Windows.Storage.Pickers;

namespace AgentX.App.ViewModels;

public partial class AuditLogViewModel : ObservableObject
{
    private readonly IAuditLogService _audit;
    private readonly IAuditLogVerifier _verifier;
    private readonly IAuditLogExporter _exporter;

    public AuditLogViewModel(IAuditLogService audit, IAuditLogVerifier verifier, IAuditLogExporter exporter)
    {
        _audit = audit;
        _verifier = verifier;
        _exporter = exporter;
    }

    [ObservableProperty] private ObservableCollection<AuditLogEntity> entries = new();
    [ObservableProperty] private long totalCount;
    [ObservableProperty] private AuditAction? actionFilter;
    [ObservableProperty] private string verificationStatus = "Not yet verified";
    [ObservableProperty] private bool isBusy;

    private const int PageSize = 100;

    [RelayCommand]
    public async Task LoadAsync()
    {
        IsBusy = true;
        try
        {
            var rows = await _audit.QueryAsync(skip: 0, take: PageSize, action: ActionFilter);
            Entries.Clear();
            foreach (var r in rows) Entries.Add(r);
            TotalCount = await _audit.CountAsync(ActionFilter);
        }
        finally { IsBusy = false; }
    }

    [RelayCommand]
    public async Task VerifyAsync()
    {
        IsBusy = true;
        try
        {
            var result = await _verifier.VerifyAsync();
            VerificationStatus = result.IsValid
                ? $"✓ Chain valid ({result.TotalEntriesChecked} entries)"
                : $"✗ Tamper detected at sequence {result.FirstTamperedSequence}: {result.Reason}";
        }
        finally { IsBusy = false; }
    }

    [RelayCommand]
    public async Task ExportCsvAsync()
    {
        var file = await PickSaveFileAsync("audit-log", ".csv");
        if (file is null) return;
        using var s = await file.OpenStreamForWriteAsync();
        await _exporter.ExportCsvAsync(s);
        await _audit.AppendAsync(new AuditEvent(AuditAction.AuditLogExported, Metadata: new System.Collections.Generic.Dictionary<string, object> { ["format"] = "csv" }));
    }

    [RelayCommand]
    public async Task ExportJsonAsync()
    {
        var file = await PickSaveFileAsync("audit-log", ".json");
        if (file is null) return;
        using var s = await file.OpenStreamForWriteAsync();
        await _exporter.ExportJsonAsync(s);
        await _audit.AppendAsync(new AuditEvent(AuditAction.AuditLogExported, Metadata: new System.Collections.Generic.Dictionary<string, object> { ["format"] = "json" }));
    }

    private static async Task<Windows.Storage.StorageFile?> PickSaveFileAsync(string name, string ext)
    {
        var picker = new FileSavePicker();
        picker.SuggestedFileName = name;
        picker.FileTypeChoices.Add(ext == ".csv" ? "CSV" : "JSON", new System.Collections.Generic.List<string> { ext });
        var hwnd = WinRT.Interop.WindowNative.GetWindowHandle(App.MainWindow);
        WinRT.Interop.InitializeWithWindow.Initialize(picker, hwnd);
        return await picker.PickSaveFileAsync();
    }
}
```

```markdown
### Audit Log (C14)

An append-only `audit_log` table records every data-mutating action. Each row carries:

- `Sequence` — monotonic PK
- `UtcTimestamp`, `Actor`, `Action`, `EntityType`, `EntityId`, `MetadataJson`
- `PrevHmac` — previous row's Hmac (or all-zeros for row 1)
- `Hmac` — `HMACSHA256(auditKey, canonicalPayload)` where `canonicalPayload = PrevHmac || "|" || fields...`

The HMAC key is 32 random bytes, DPAPI-wrapped in `UserSettings.DpapiWrappedAuditKey`. Only the current Windows user can derive it, so a database-level compromise cannot forge entries.

`IAuditLogVerifier.VerifyAsync()` walks the chain from `Sequence=1`, recomputes every Hmac, and reports the first tampered sequence number. Any row tamper (insert / delete / reorder / field edit) is detected.

Viewer: `AuditLogPage`. Export: CSV + JSON via `IAuditLogExporter`. Export itself is audited (`AuditAction.AuditLogExported`).
```
