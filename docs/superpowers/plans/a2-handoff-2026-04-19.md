## Critical deviations / judgment calls already made

These are in the commit bodies but flagged here so future-me doesn't re-investigate.

### Task 2 (IShortcutRegistry) — additive until Task 10
- Plan's Files header said "rename KeyboardShortcutService → ShortcutRegistry" but the Step 4 impl is in `namespace AgentX.Core.Services.Shortcuts`.
- Resolution: Task 2 landed additively, then Task 10 performed the actual migration. `AgentX.App.Services.KeyboardShortcutService` has been removed from the active codebase; global descriptors now seed through `ShortcutCatalog`.

### Task 3 (FuzzyMatcher) — two deviations
1. **Added pure-prefix bonus** (`+needle.Length * 2` when match is consecutive from position 0). Without it, per-char accumulation let long-suffix matches out-score short-prefix matches (`"document"` beat `"import"` 26→25 on haystack `"import document"`).
2. **Reconciled internal test contradiction.** Plan's `Rank_orders_best_match_first` expected `"Chat"` last, but `Rank_excludes_zero_scores` expects zero-score items filtered entirely. Aligned to the explicit filter contract — zero-scorers are excluded, not ordered-last.

### Task 5 (CommandPalette) — XAML integration still pending
- Plan referenced `src/AgentX.App/Views/CommandPalette.xaml`. Actual path is `src/AgentX.App/Controls/CommandPalette.xaml`.
- Existing palette is a **callback-based UserControl** (`NavigateToPageRequested`, `ExecuteActionRequested`), NOT a VM-bound ContentDialog. Re-binding its ListView to `ViewModel.Results` without first seeding the registry with matching descriptors would leave a half-wired palette with no items.
- **Delivered in Task 5 commit**: `CommandPaletteViewModel.cs` (in `AgentX.App/ViewModels/`, linked into AgentX.Tests via `<Compile Include>` same as QuickChatViewModel) + 4 tests.
- **Still pending after Task 10**: the actual XAML/rendering binding flip + code-behind rewire to use the VM. Task 10 migrated global shortcut seeding and removed the legacy shortcut service; it did not rewrite the existing callback-rendered palette UI.
- Existing hardcoded Quick-Actions in the palette continue to work unchanged until that UI rewire lands.
