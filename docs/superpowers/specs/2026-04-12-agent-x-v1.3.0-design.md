## 1. Executive Summary

Agent-X v1.3.0 is the **most ambitious release yet**, introducing architectural changes that enable enterprise-scale usage and ecosystem growth. This version transforms Agent-X from a single-user tool into a **multi-workspace platform** with advanced collaboration foundations.

**Goals:**
- Multiple isolated workspaces (Work, Research, Personal) with separate databases
- Smart Inbox for watch folder triage with AI-powered suggestions
- Comparative Analysis for side-by-side document comparison
- Voice input and audio file transcription (Whisper)
- Plugin API scaffold for extensibility
- Collaborative sync foundation (CRDT research, change tracking)

**Success Criteria:**
- Users can switch between workspaces instantly; each has isolated data
- New files from watch folders land in Inbox with AI preview and suggestions
- Select 2+ documents → "Compare" generates structured comparison report
- Push-to-talk voice input works in chat; audio files transcribe on import
- Plugin SDK NuGet package exists; sample plugin loads successfully
- Change tracking enabled on all entities for future sync

**Implementation Note:** Workspace switching is complex with singleton DbContext. Two approaches:

1. **Restart-based (simpler):** Switching workspaces restarts the app with new DB path
2. **Scoped DbContext (complex):** Refactor DbContext to be scoped per workspace with connection pooling

**Recommended:** Start with restart-based; refactor to scoped if user feedback demands instant switching.

### 6.5 Transcription Service

```csharp
public class TranscriptionService : ITranscriptionService
{
    private readonly ISettingsService _settingsService;
    private WhisperFactory? _factory;

    public async Task InitializeAsync(string modelName = "tiny")
    {
        var modelPath = Path.Combine(_settingsService.ModelsPath, $"ggml-{modelName}.bin");

        // Download model if not present
        if (!File.Exists(modelPath))
        {
            await DownloadWhisperModelAsync(modelName, modelPath);
        }

        _factory = WhisperFactory.FromPath(modelPath);
    }

    public async Task<TranscriptionResult> TranscribeAsync(
        Stream audioStream,
        string? language = null,
        CancellationToken ct = default)
    {
        var builder = _factory!.CreateBuilder()
            .WithLanguage(language ?? "auto");

        await using var processor = builder.Build();
        var segments = new List<TranscriptionSegment>();

        await foreach (var segment in processor.ProcessAsync(audioStream, ct))
        {
            segments.Add(new TranscriptionSegment
            {
                Start = segment.Start,
                End = segment.End,
                Text = segment.Text,
                Speaker = segment.Speaker // If diarization enabled
            });
        }

        return new TranscriptionResult
        {
            FullText = string.Join(" ", segments.Select(s => s.Text)),
            Segments = segments,
            Duration = segments.Last().End - segments.First().Start,
            Language = language ?? "en"
        };
    }
}
```

### 6.6 Audio Processor

```csharp
public class AudioProcessor : IDocumentProcessor
{
    private readonly ITranscriptionService _transcriptionService;

    public bool CanProcess(string filePath)
    {
        var ext = Path.GetExtension(filePath).ToLowerInvariant();
        return ext is ".mp3" or ".wav" or ".m4a" or ".flac" or ".ogg";
    }

    public async Task<ProcessedDocument> ProcessAsync(string filePath)
    {
        var transcription = await _transcriptionService.TranscribeAsync(
            File.OpenRead(filePath));

        return new ProcessedDocument
        {
            Text = transcription.FullText,
            Title = Path.GetFileNameWithoutExtension(filePath),
            Language = transcription.Language,
            Metadata = new AudioMetadata
            {
                Duration = transcription.Duration,
                SegmentCount = transcription.Segments.Count,
                HasDiarization = transcription.Segments.Any(s => !string.IsNullOrEmpty(s.Speaker))
            },
            WordCount = transcription.FullText.Split(' ').Length,
            PageCount = 0 // Audio doesn't have pages
        };
    }
}
```

public class PluginManager : IPluginManager
{
    private readonly string _pluginsDirectory;
    private readonly Dictionary<string, IPlugin> _loadedPlugins;

    public async Task LoadPluginAsync(string pluginPath)
    {
        var manifest = await PluginManifest.LoadAsync(Path.Combine(pluginPath, "manifest.json"));

        var loadContext = new PluginLoadContext(pluginPath);
        var assembly = loadContext.LoadFromAssemblyPath(Path.Combine(pluginPath, manifest.EntryPoint + ".dll"));

        var pluginType = assembly.GetType(manifest.EntryPoint);
        var plugin = (IPlugin)Activator.CreateInstance(pluginType)!;

        await plugin.InitializeAsync(_pluginHost);
        _loadedPlugins[manifest.PluginId] = plugin;
    }

    public void UnloadPlugin(string pluginId)
    {
        if (_loadedPlugins.TryGetValue(pluginId, out var plugin))
        {
            plugin.DeactivateAsync().GetAwaiter().GetResult();
            plugin.Dispose();
            _loadedPlugins.Remove(pluginId);
        }
    }
}

### 8.3 Change Tracking

```csharp
// Base entity with change tracking
public abstract class TrackableEntity
{
    public long Id { get; set; }
    public DateTime CreatedAt { get; set; } = DateTime.UtcNow;
    public DateTime ModifiedAt { get; set; } = DateTime.UtcNow;
    public bool IsDeleted { get; set; }
    public string? SyncStateJson { get; set; } // For CRDT metadata
}

// In DbContext
public override int SaveChanges()
{
    foreach (var entry in ChangeTracker.Entries<TrackableEntity>())
    {
        if (entry.State == EntityState.Modified)
        {
            entry.Entity.ModifiedAt = DateTime.UtcNow;
        }
        else if (entry.State == EntityState.Deleted)
        {
            // Soft delete for sync
            entry.Entity.IsDeleted = true;
            entry.Entity.ModifiedAt = DateTime.UtcNow;
            entry.State = EntityState.Modified;
        }
    }

    return base.SaveChanges();
}
```

### 8.4 Encrypted Delta Export

```csharp
public class SyncExportResult
{
    public byte[] EncryptedData { get; set; } = null!;
    public DateTime FromDate { get; set; }
    public DateTime ToDate { get; set; }
    public string Checksum { get; set; } = "";
}

public async Task<SyncExportResult> ExportChangesAsync(
    DateTime from,
    DateTime to,
    string encryptionKey)
{
    var changes = new
    {
        Conversations = await _db.Conversations
            .Where(c => c.ModifiedAt >= from && c.ModifiedAt <= to)
            .ToListAsync(),
        Messages = await _db.Messages
            .Where(m => m.ModifiedAt >= from && m.ModifiedAt <= to)
            .ToListAsync(),
        Documents = await _db.Documents
            .Where(d => d.ModifiedAt >= from && d.ModifiedAt <= to)
            .ToListAsync()
        // ... all other entities
    };

    var json = JsonSerializer.Serialize(changes);
    var jsonBytes = Encoding.UTF8.GetBytes(json);

    // AES-256 encrypt
    var encrypted = await _aesEncryptor.EncryptAsync(jsonBytes, encryptionKey);

    return new SyncExportResult
    {
        EncryptedData = encrypted,
        FromDate = from,
        ToDate = to,
        Checksum = ComputeChecksum(encrypted)
    };
}
```

## 10. Security Considerations

### 10.1 Plugin Security

- Plugins run in isolated `AssemblyLoadContext`
- No direct file system access — must go through `IPluginHost.FileSystem`
- No network access unless explicitly granted in manifest permissions
- Plugin assembly is not loaded into main AppDomain

### 10.2 Sync Security

- Encrypted delta format: AES-256-CBC
- Key derivation: PBKDF2 with 100,000 iterations
- Sync folder contents are unreadable without Agent-X
- User provides their own storage (OneDrive, NAS, etc.) — no cloud dependency

### 10.3 Workspace Isolation

- Workspaces are logically isolated (separate DB files)
- No cross-workspace data leakage
- Backup/Restore is workspace-aware
